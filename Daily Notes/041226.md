### Yandex S3 CSI Driver Module Created

**New Module**: `helm-s3-csi/`
- Complete Terraform module for Yandex Cloud S3 CSI driver
- OCI-based Helm chart from Yandex Cloud marketplace
- Supports multiple S3 providers: Yandex Object Storage, AWS S3, MinIO, QNAP NAS

**Architecture**:
- FUSE-based mounter (geesefs/rclone/s3backer)
- Creates StorageClass `csi-s3` for dynamic PV provisioning
- Kubernetes Secret for S3 credentials
- 5-level override hierarchy compliant

**Key Files**:
- `helm-s3-csi/main.tf` - Namespace, Secret, StorageClass, Helm release
- `helm-s3-csi/variables.tf` - All S3 CSI configuration variables
- `helm-s3-csi/locals.tf` - Override hierarchy implementation
- `helm-s3-csi/templates/s3-csi-values.yaml.tpl` - Helm values template

- Rook v18.2.4 OSDs require block volume mode
- Solution: Pivot to S3 CSI for object storage use cases
