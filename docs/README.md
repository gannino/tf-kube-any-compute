## 📖 Documentation Conventions

### File Naming
- Use `UPPERCASE-WITH-HYPHENS.md` for documentation files
- Use descriptive names that clearly indicate content
- Group related documentation in appropriate subdirectories

### Internal Links
- Use relative paths for links within documentation
- Link to specific sections using anchors when appropriate
- Keep links up-to-date when moving files

### Content Structure
- Start with a clear title and overview
- Use emoji for visual organization (sparingly)
- Include code examples and configuration snippets
- Provide troubleshooting sections where applicable
